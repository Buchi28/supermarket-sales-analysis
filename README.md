# Supermarket Sales Analysis

## Project Overview
This project analyses supermarket sales data using Microsoft Excel and MySQL to identify revenue trends, customer purchasing behaviour, popular payment methods, and customer ratings.

The goal is to turn raw sales data into useful business insights that can support better decision-making.

## Tools Used
- Microsoft Excel: Data cleaning, exploration, and dashboard creation.
- MySQL: Data querying, aggregation, and business analysis.

## Business Questions
1. Which branch generates the highest revenue?
2. Which product line generates the highest revenue?
3. Which payment method is most popular?
4. Which branch has the highest average customer rating?
5. Do members or normal customers spend more per transaction?
6. What are the total revenue, quantity sold, and average transaction value?

## Project Process
1. Inspected and cleaned the dataset in Excel.
2. Imported the cleaned data into MySQL.
3. Used SQL aggregate functions, grouping, sorting, and distinct counts to answer business questions.
4. Summarised the findings and developed business recommendations.
5. Prepared an Excel workbook to present the analysis.

## Key Findings
- Highest-revenue branch: [C]
- Highest-revenue product line: [Food and beverages]
- Most popular payment method: [Ewallet]
- Highest average customer rating: [4.7]
- Higher average spend by customer type:[322.9]

## Business Recommendations
- Investigate the sales patterns of the highest-revenue branch.
- Monitor product demand and stock availability across product lines.
- Continue supporting customer payment methods and monitor changes in usage.
- Investigate customer feedback to identify opportunities to improve satisfaction.
- Compare spending patterns between membership groups without assuming membership causes higher spending.
